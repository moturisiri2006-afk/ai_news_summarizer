# 📰 AI News Summarizer

## 📌 Project Description

AI News Summarizer is a Python-based application that fetches the latest news from a selected category using NewsAPI and generates concise AI-powered summaries using Google's Gemini model. Users can choose how many articles to summarize, and the generated summaries are saved for future reference.

---

## ✨ Features

- ✅ Fetch latest news using NewsAPI
- ✅ Generate AI-powered summaries using Gemini AI
- ✅ Save summaries in JSON format
- ✅ Record application logs
- ✅ Allow users to choose the number of articles to summarize
