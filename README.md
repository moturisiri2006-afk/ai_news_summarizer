## 📌 Project Description

AI News Summarizer is a Python-based web application that fetches the latest news using NewsAPI and generates AI-powered summaries with Google Gemini. Users can browse news by country and category, search for specific topics, and view AI-generated key points, sentiment analysis, and takeaways through an interactive Streamlit interface.

---

## ✨ Features

- 🌍 Browse news by country
- 📰 Filter news by category
- 🔍 Search news using keywords
- 🤖 Generate AI-powered summaries using Google Gemini
- 📌 AI-generated key points
- 😊 Sentiment analysis
- 💡 AI takeaway for every article
- 🖼️ Display article images
- 📅 Show publication date
- 🔗 Read the original article
- 💾 Save summaries in JSON format
- 📝 Application logging
- 🎨 Interactive Streamlit interface
